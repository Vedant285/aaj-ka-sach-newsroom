# Hindi font

NotoSansDevanagari.ttf is the unmodified Noto Sans Devanagari variable font from
Google Fonts, distributed under the adjacent OFL.txt. Keep both files together.

Source commit: `2bc5d431b584d89e646214bf6cfa75494e76ceea`

Source: https://github.com/google/fonts/blob/2bc5d431b584d89e646214bf6cfa75494e76ceea/ofl/notosansdevanagari/NotoSansDevanagari%5Bwdth%2Cwght%5D.ttf

SHA-256: `14ec4af41f27482216d1c2229f417ff9b1425e1babb014e57d1d40d03229853e`

The font is bundled so rendering does not require a network font download or a
system-installed Hindi font on Windows or the Linux GitHub Actions runner.
